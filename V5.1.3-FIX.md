# VidSnatch V5.1.3 Fix

## bgutil Windows startup

The development launcher now prefers port 4416 but automatically selects a free IPv4 localhost port when 4416 is occupied by another process. The selected port is passed to the backend through `BGUTIL_POT_BASE_URL`. A healthy existing bgutil instance on 4416 is reused.

This prevents a common Windows failure where the bgutil child process remains alive after Express reports `EADDRINUSE`, causing the old launcher to wait forever for `/ping`.
