X / Twitter Video Downloader

VidSnatch provides a simple web-based interface for processing supported X and Twitter video links. Paste a video URL into the downloader above and, when available, select the format or quality you prefer.

How to download an X or Twitter video

  1. Open X or Twitter and copy the URL of the post containing the video you want to process.
  2. Paste the video URL into the VidSnatch input box.
  3. Select Fetch Video.
  4. Wait for the available video information and formats to appear.
  5. Select an available download option.

Simple browser-based video downloading

VidSnatch is designed to keep the video processing experience straightforward. You can use the service through a modern web browser without installing a separate desktop application.

Video availability

Only URLs that can be processed by the VidSnatch backend are supported. Private posts, restricted content, deleted posts, or unavailable sources may not be processable.
