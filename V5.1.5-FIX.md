# VidSnatch V5.1.5 UI / SEO Fixes

Visual-only polish based on V5.1.4. Downloader/fetch/download backend behavior is unchanged.

- Fixed day/night theme surfaces with a true dark palette and no light neumorphic glow in night mode.
- Removed URL input borders, link-icon styling, focus halos, and URL-area shadows in both themes.
- Removed the optional raw video preview element from the visible UI so selecting a quality never creates a black screen below the thumbnail.
- Preserved the fetched thumbnail at its existing 16:9 display size.
- Kept the shared navbar/theme/language shell intact across all pages.
- Added/normalized SEO metadata on all dedicated downloader pages: keywords, author, theme color, Open Graph image metadata, Twitter large-image metadata, and BreadcrumbList structured data.
- Home page SEO structure remains intact and receives the same breadcrumb consistency.

No downloader API, fetch, format selection, or download logic was intentionally changed.
